# Focus — SmartGallery 📷

## 📚 Sobre o projeto

A **Focus SmartGallery** é uma solução desenvolvida para auxiliar estudantes universitários full-time na organização de conteúdos acadêmicos dentro da galeria do celular.

O projeto busca resolver o problema do chamado **“cemitério digital”**, situação em que centenas de fotos de anotações, trabalhos, slides e conteúdos importantes acabam esquecidos e desorganizados na galeria do dispositivo.

A proposta da solução é utilizar inteligência artificial para:

- identificar imagens relacionadas aos estudos;
- organizar automaticamente os conteúdos por matérias;
- detectar datas importantes presentes nas imagens;
- reduzir o acúmulo de fotos esquecidas;
- proporcionar uma experiência mais produtiva e organizada para estudantes.

---

# 🚀 Funcionalidades

## Landing Page Interativa
A aplicação possui uma landing page moderna e responsiva apresentando:

- problema identificado;
- solução SmartGallery;
- benefícios da plataforma;
- acesso ao protótipo no Figma.

---

## 📱 Slideshow Dinâmico
Foi implementado um slideshow utilizando JavaScript para alterar dinamicamente o background da seção principal da página.

### Funcionalidades:
- troca manual de imagens;
- botões de próximo e anterior;
- manipulação dinâmica do DOM;
- alteração do `background-image` via JavaScript.

---

## 📝 Formulário Inteligente
A aplicação possui um formulário de personalização da experiência do usuário.

### O formulário permite:
- descrever a rotina de estudos;
- definir preferências de organização;
- selecionar método de exclusão de imagens;
- escolher prioridades acadêmicas.

---

## ⚡ Validações e Eventos
Foram implementadas validações utilizando JavaScript:

- `alert()`
- `confirm()`
- manipulação de eventos
- validação de campos vazios
- validação de checkboxes

---

## 💾 Session Storage
Os dados do usuário são armazenados utilizando `sessionStorage`.

### Objetivo:
Manter as informações apenas durante a sessão do navegador, garantindo uma experiência temporária e evitando o acúmulo desnecessário de dados.

Os dados são automaticamente removidos ao fechar a aba do navegador.

---

## 📊 Dashboard Dinâmico
Após o formulário, o usuário é redirecionado para um dashboard personalizado contendo:

- informações da rotina do usuário;
- preferências selecionadas;
- prioridades acadêmicas;
- alertas inteligentes simulados.

As informações são renderizadas dinamicamente utilizando JavaScript e manipulação do DOM.
